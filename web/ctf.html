Hint system

Every challenge has three hints. Hints point toward the technique — never the exact payload. Unlocking costs a percentage of that challenge's points: Hint 1 -10% · Hint 2 -20% · Hint 3 -30%. No-hint solvers earn the No-Hint Solver achievement.

Lab rules

  • AUTHORIZED LAB ONLY. Attack only the lab target (127.0.0.1 / your lab VM). Never point these techniques at systems you do not own.
  • No real credentials, personal data or external targets are used or allowed.
  • Do not DoS the lab or other players. Submission cooldown is 3 seconds.
  • Flags are case-sensitive: VULNLAB{...}, CVE or CWE identifiers.
  • Wrong answers cost nothing. Hints cost points.
  • First blood on a challenge: +20% (cap 50 pts).
  • Collaborate on technique, submit your own flags.

CVE disclaimer

Some challenges are inspired by historical CVEs. The lab may emulate the vulnerability's security condition rather than running the original vulnerable software. CVE references are provided for vulnerability research and learning.

The lab never requires attacking an external system. Simulated CVE challenges are answered with the CVE identifier itself — verify affected versions and prerequisites before claiming a match.

Final report template (10 sections — screenshots required)

  1. Recon
  2. Attack surface
  3. Vulnerability
  4. Evidence
  5. Exploitation methodology
  6. Impact
  7. Flag
  8. Remediation
  9. CWE
  10. CVE (if applicable)

Writeups stay with you — the answer key is instructor-only. Solve challenges, then map each one to its CWE and (where applicable) its CVE.

# report skeleton
1. Recon          : nmap -sC -sV -p- 10.x.x.x
2. Attack surface : 2121/tcp ftp, 2222/tcp ssh, 2323/tcp telnet, 445/tcp smb,
                    5000/tcp http, 5050/tcp waf, 9090/tcp ctf + hidden services
3. Vulnerability  : e.g. missing authorization on /api/v1/profile/<id>
4. Evidence       : request/response pairs (Burp/curl)
5. Methodology    : observation -> hypothesis -> enumeration -> validation
6. Impact         : what an attacker gains
7. Flag           : VULNLAB{...}
8. Remediation    : server-side authorization checks, least privilege
9. CWE            : CWE-639
10. CVE           : CVE-XXXX-YYYYY (if applicable)
